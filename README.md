# EMYRGEN — Brazil Climate Infrastructure (Investor Briefing)

A cinematic, vertical 24-scene investor presentation (HTML/CSS/JS, no build step).

## Run locally
Open `index.html` in any modern browser.

## Deploy on GitHub Pages
1. Push this folder to a repository.
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. The deck is served from `index.html`.

## Files
- `index.html` — intro scene + shell
- `app.js` — 24 investor scenes + playback logic
- `styles.css` — visual design
- `assets/` — scene imagery and logo

Controls: Prev / Pause / Replay / Next · arrow keys · spacebar · swipe.
